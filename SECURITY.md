# Security Policy

This repository is a deliberately sanitized public technical excerpt of SHUUR. It is not the production deployment repository.

## Reporting a security issue

Do not publish suspected vulnerabilities, credentials, or sensitive production details in a public GitHub issue.

Security-sensitive reports concerning SHUUR should be sent privately to OXFORDER LLC through the official contact channel listed on https://oxforder.uz or https://shuur.uz.

## Scope

The public repository contains no intended production secrets or user data. If a credential, private key, service-account value, user record, or other sensitive production artifact is discovered here, treat it as an unintended disclosure and report it privately.
